# Cashier Quick Reference — Cup Shup POS

Print this. Tape it by the register.

## Taking an order

| Key | Does |
|---|---|
| `1`–`9` | Add the Nth item shown on screen right now |
| `*` then a digit | Set quantity for the next item you pick — `*6` then `3` = 6× item #3 |
| `/` | Jump to search (type a name, or scan a barcode — same thing) |
| `Enter` | Send the order to the kitchen |
| `F2` | Send **and** go straight to payment |
| `F4` | Void this order (needs a manager's PIN) |
| `Esc` | Clear what you've typed so far, start over |
| `Ctrl+R` | Repeat the last order you sent — same table ordering again |
| `?` | Show this list on screen |

## A normal order, start to finish

1. Pick **Dine-in / Takeaway / Delivery**.
2. Dine-in: tap the table. Delivery: enter the phone number.
3. Punch in items with `1`–`9` (or search with `/`).
4. `Enter` to send to the kitchen, or `F2` to send and go straight to payment.
5. On the payment screen: pick the method(s), enter the amount, `Settle`.
6. Print the receipt.

## If something's wrong

- **Wrong item punched in** → remove it from the cart before sending
  (it's just a draft until you hit `Enter`/`F2`).
- **Already sent, need to void** → `F4`, then a manager enters their own
  PIN, then pick a reason.
- **Screen says "Offline"** → see the separate "internet band ho to kya
  karein" sheet. Short version: keep taking orders, they queue and send
  automatically once the connection is back.
- **Printer error** → the order is already saved regardless. Try
  printing again in a minute; if it still fails, tell a manager — it
  goes into a retry list, nothing is lost.
